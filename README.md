# swissgeol-animations

Nachbauten von [swissgeol](https://swissgeol.ch)-Assets, um Animationen von Features zu erstellen, die es in der Live-Umsetzung noch nicht gibt.

## Entwicklung

```bash
npm install
npm run dev
```

## Deployment

Jeder Push auf `main` wird automatisch auf Vercel deployed. Pull Requests erhalten Preview-Deployments.
